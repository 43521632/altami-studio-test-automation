# Инструкция для AI — проект автотестов Altami Studio

## 1. Цель

Переделать текущие тесты так, чтобы они были **изолированы друг от друга**. Каждый тест должен запускаться из гарантированно чистого состояния приложения (не ВМ).

**Архитектура:**
1. **Однократная подготовка ВМ** (до всех тестов): восстановление снапшота, получение установщика, запуск ВМ.
2. **Один тест установки** — устанавливает приложение, выполняет первичную настройку, закрывает приложение.
3. **Все остальные тесты** — запускают приложение, проверяют, закрывают. Каждый тест начинается с чистого запуска и не влияет на другие.

**Источники данных:**
- Ревизия сборки — из CI (переменная `BUILD_REVISION`) или аргумент `--revision`.
- Версия продукта — из CI (`APP_VERSION`), аргумента `--app-version` или файла `VERSION` в корне проекта.
- Установщик — скачивается с `https://cache.altami.ru/artifactory/app-builds/altami/{revision}/{platform}/AS_{version}_{revision}_{platform}.{ext}`.
- Аутентификация — логин/пароль из `CACHE_USER`/`CACHE_PASSWORD`.

## 3. Что нужно доделать (TODO)

### 3.1. Высокий приоритет (блокирует работу)

#### a) Реализовать копирование установщика на ВМ
**Файл:** `utils/vm_operations.py`, функция `copy_file_to_vm()`.

**Варианты реализации:**
- **SCP** — если на ВМ настроен SSH (порт 22). Использовать `paramiko` или `scp`.
- **Shared folder** — если папка смонтирована в гостевой ОС (например, `/mnt/host`). Просто копировать через `cp`.
- **QEMU guest agent** — через `guest-file-open`/`guest-file-write` (требует доработки QMP-клиента).

**Рекомендация:** начать с SCP, если SSH доступен.

#### b) Реализовать установку приложения
**Файл:** `utils/app_operations.py`, функция `install_app()`.

**Что нужно:**
- Запустить установщик на ВМ (через UI или тихий режим).
- Дождаться завершения установки.
- Выполнить первичную настройку (если требуется).
- Закрыть приложение.

**Рекомендация:** использовать тихий режим установщика (ключи `/quiet`, `/silent`), если он поддерживается. Иначе — автоматизация через QMP (клики, ввод текста).

#### c) Реализовать запуск/остановку приложения

- Остановка: закрыть окно (Alt+F4, клик по крестику) или завершить процесс.

**Рекомендация:** использовать QMP для эмуляции мыши/клавиатуры.

## 4. Как использовать новую систему

### 4.1. Локальный запуск с указанием ревизии
```bash
pytest tests/ --revision=88034f7d4 --app-version=4.2.0
```

### 4.2. Использование локального установщика (без скачивания)
```bash
pytest tests/ --installer-path=/path/to/AS_4.2.0_88034f7d4_windows-x86_64.exe
```

### 4.3. Запуск только теста установки
```bash
pytest tests/test_install.py
```

### 4.4. Запуск конкретного теста с ID
```bash
pytest tests/ --case TC-85
```

### 4.5. Переменные окружения (для CI)
```bash
export BUILD_REVISION=88034f7d4
export APP_VERSION=4.2.0
export CACHE_USER=username
export CACHE_PASSWORD=password
export VM_ID=windows   # или astra
pytest tests/
```
